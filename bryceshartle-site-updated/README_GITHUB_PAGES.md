# Vite + React + TypeScript Project (GitHub Pages Ready)

This folder is ready to be pushed directly to a GitHub repository.

## Run Locally

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```

The static files will be created in the `dist` folder.

## Deploy to GitHub Pages (Recommended)

1. Push this folder as the root of a GitHub repository.
2. Use a GitHub Action or a local build to publish the contents of `dist/` to the `gh-pages` branch.
3. In your repository settings, enable GitHub Pages for the `gh-pages` branch.
4. Point your custom GoDaddy domain's DNS records (CNAME) to your GitHub Pages URL.
